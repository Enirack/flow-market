# Docker

Ce répertoire contiendra les Dockerfiles de production par application
(`web`, `admin`, `api`, `worker`) ainsi que les scripts d'initialisation
d'infrastructure. Le `docker-compose.yml` à la racine du repo couvre les
services d'infrastructure de développement (PostgreSQL, Redis, Meilisearch).

Les Dockerfiles de production seront ajoutés en Phase 12 (production
hardening).
