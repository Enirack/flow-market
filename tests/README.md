# Tests end-to-end transverses

Ce répertoire contiendra les scénarios Playwright qui couvrent des parcours
traversant plusieurs applications (ex : parcours client complet du login au
paiement). Les tests unitaires/intégration propres à une app ou un package
vivent à côté du code qu'ils testent (`apps/*/src`, `packages/*/src`).

Mis en place à partir de la Phase 1 (foundation) et complété à chaque phase
fonctionnelle.
